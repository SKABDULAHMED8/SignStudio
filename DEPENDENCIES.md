# Third-party dependencies and licenses

| Package | Role | License |
|---|---|---|
| `vite` | Development server and static build | MIT |
| `@playwright/test` | Chromium end-to-end browser tests | Apache-2.0 |
| `pdfjs-dist` | Lazy-loaded PDF parsing and rendering | Apache-2.0 |
| `pdf-lib` | Lazy-loaded PDF form editing and export | MIT |

The application uses browser-native Canvas, Web Crypto, IndexedDB, Cache Storage, Service Workers, Pointer Events and File APIs. The unit suite uses Node.js built-in `node:test`; no test runner package is required.

All runtime dependencies are installed from npm during development and bundled into the static build. PDF libraries are loaded only when the PDF workspace is opened. No package is loaded from a CDN. Original application icons and PWA icons are stored locally under `public/`; no remote icon library or font is used.

License statements above describe the declared package licenses. Check installed package notices and transitive dependency notices before redistributing a public build. A lockfile should be generated by `npm install` in a network-enabled environment and committed before a reproducible release.
